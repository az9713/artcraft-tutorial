Artcraft Adobe Map

Sources: GitHub org page github.com/orgs/storytold/repositories (2 pages, 41 repos), the READMEs of effectcraft and designcraft, and the YouTube video "Someone Just Rebuilt Adobe for Free, and Claude Can Run Them All (7 apps tested)" by Jay E | RoboNuggets (Fuo1i_-9Frc). Date: 2026-10-08.

Thesis

The GitHub organization storytold (the group the video calls Artcraft) publishes 12 desktop applications that each copy the interface of one commercial product. Seven of them copy an Adobe product. Five copy other vendors. All 12 are written in Rust. The video claims that Claude Opus 5.5 produced them as "clean room reimplementations", which means they were written from scratch and not by reverse engineering Adobe software. The video and the READMEs make this claim. I did not inspect source code to verify it.

Detail on the two repos checked

effectcraft is a motion graphics and compositing application. Its README lists compositions, layers and keyframes, 306 effects, layer styles, expressions, 3D cameras and lights, a render queue, and Lottie import and export. Project files use readable, versioned JSON with the extension .ecproj. It does not depend on FFmpeg. The README states that the project is young and is not yet a full replacement for After Effects. It cannot open .aep files. The video author called After Effects the most complex Adobe product to recreate, so the missing .aep import is a material limit for anyone with existing projects.

designcraft is a page layout application that runs on macOS, Windows, Linux, and in the browser through WebAssembly. It has spreads, parent pages, threaded text frames, and paragraph and character styles. It uses a Knuth–Plass paragraph composer so that line breaks match on screen and in PDF output. It imports and exports IDML (the InDesign interchange format) and exports PNG. PDF export is planned and is not yet present. Both repos use the license "MIT or Apache-2.0, at your option".

Agent control

Both READMEs describe a command line tool and an MCP server mode: effectcraft-cli and designcraft-cli. Both repos contain an AGENTS.md file. That file holds the clean-room rules, the asset policy, and the quality gates. The video says this design is why Claude can drive the applications. The video author tested two cases. A logo animation in effectcraft and a magazine spread in designcraft were each produced from one prompt, as a first draft with editable layers. The author states that the output is "somewhat okay" and easier to refine than a single-prompt generated image, because each layer stays separate.

Other repositories

Five more craft applications copy non-Adobe products: wordcraft (Word, 533 stars), gridcraft (Excel, 327), deckcraft (PowerPoint, 288), soundcraft (Pro Tools, 340), and cadcraft (CAD and drafting, 470; the page names no vendor). The video does not mention them. Supporting repos are artcraft (6.3k stars, "creative engine"), artcraft-services (backend and web frontend), craft-fonts, photocraft-corpus (test data), artcraftx, and github-media. The remaining 29 repos date from 2020 to 2025. They are Unreal Engine 4 plugins, Azure Kinect tools, motion capture and voice model experiments, and infrastructure code. The org worked on those topics before the craft apps.

How to install each craft from Claude Code or Codex

Each repo publishes ready-made installers, so you do not need to compile anything. The READMEs list these release files: for Windows, an .msi installer and a -portable.zip (x64, arm64, x86); for macOS, a universal .dmg for the app and a universal -cli .zip; for Linux, AppImage, Flatpak, .deb, .rpm and .tar.gz (x86_64, aarch64). A SHA256SUMS.txt file lists a checksum for every file. The READMEs say Windows files are code-signed and macOS files are signed and notarized. None of them says how to deal with a SmartScreen or Gatekeeper warning. The site getartcraft.com/apps lists "Installers ready" for all 7 apps but shows no version numbers or direct links in the text that I read. The apps are early alpha (photocraft, pdfcraft) or "in development" (the other five).

Rule for every step: the agent may download files and run installers on your computer. Start each session by telling the agent to show the plan and wait. Run the install in an empty folder, because downloaded files are untrusted.

The same six steps for all 7 apps

Open Claude Code or Codex in a new empty folder, for example craft-install. Give the agent each prompt in turn. Replace CRAFT with the repo name, for example pdfcraft.

  1. Check the machine.
    "Tell me my operating system, my CPU type (x64 or arm64), and whether Rust, git and the GitHub CLI are installed. Do not install anything yet."
  2. Find the right file.
    "Look at the latest release of github.com/storytold/CRAFT. List the files. Pick the installer that fits my machine. Tell me the file name, its size and its version. Wait for my yes."
  3. Download and verify.
    "Download that file and SHA256SUMS.txt into this folder. Check the file against the checksum. Tell me if they match. Stop if they do not."
  4. Install.
    "Install it. On Windows, run the .msi. On macOS, mount the .dmg and copy the app to Applications. On Linux, use the AppImage, or the .deb or .rpm if I prefer a system install. Tell me before each step that needs administrator rights."
  5. Get the command line tool.
    "I also want CRAFT-cli so that you can drive the app. Find it in the release files. If the release has no CLI file for my system, ask me before you build it from source."
  6. Connect it to you.
    "Register CRAFT-cli as an MCP server for this agent. Show me the exact command or config entry first. Then restart if needed and list the tools you can now call." (Config entries are in the Codex configuration card below.)

The README names a CLI file only for macOS (CRAFT-cli-<ver>-macos-universal.zip). The text I read does not say whether the Windows and Linux installers include the CLI. That is why step 5 allows a source build.

Option B for all 7 apps: build from source

Use this when no installer fits, for example on a Windows arm64 machine without a matching file, or when you want the CLI. You need git and Rust. The effectcraft README says Rust 1.95 or newer. The other READMEs give no version, so use the same.

  1. "Check that Rust 1.95 or newer is installed. If not, tell me how to install it with rustup and wait for my yes."
  2. "Clone github.com/storytold/CRAFT into this folder and read AGENTS.md and the README. Tell me the build commands in your own words."
  3. "Build the release version of the app and of CRAFT-cli. Tell me where the binaries are." (The READMEs do not say where cargo puts the files. The default is target/release inside the repo. The lightcraft MCP example uses "$PWD/target/release/lightcraft-cli".)
  4. "Run the quick check from the README and show me the output."

pdfcraft — install

Files: pdfcraft-<ver>-windows-x64.msi, pdfcraft-<ver>-macos-universal.dmg, pdfcraft-cli-<ver>-macos-universal.zip, plus Linux and FreeBSD files. Status: early alpha.

One-prompt version: "Install pdfcraft from the latest release at github.com/storytold/pdfcraft for my machine. Download the installer and SHA256SUMS.txt, verify the checksum, show me the plan, wait for my yes, then install. Then get pdfcraft-cli and register it as an MCP server limited to the folder ~/Documents/pdfs with --root."

Check it works: "Create a one-page sample PDF and run pdfcraft-cli info on it. Show me the JSON." Source build: cargo run --release -p pdfcraft -- some.pdf.

photocraft — install

Files: photocraft-<ver>-macos-universal.dmg, photocraft-cli-<ver>-macos-universal.zip, Windows .msi, Linux, FreeBSD. Status: early alpha. Linux Flatpak needs the freedesktop runtime from Flathub. An AppImage needs no install; on the first run it adds a launcher entry in ~/.local/share (set PHOTOCRAFT_NO_DESKTOP_INTEGRATION=1 to skip that).

One-prompt version: "Install photocraft from github.com/storytold/photocraft for my machine. Use the latest release, verify the checksum, show me the plan and wait for my yes. Then install photocraft-cli, register it as an MCP server, and tell me the tools you can call."

Check it works: "Run photocraft-cli batch --help and explain the options." Source build: cargo run --release -p photocraft -- image.psd. Reading HEIC photos needs the build option --features heif, which official builds include.

lightcraft — install

The README says the easiest install is the LightCraft page on getartcraft.com. Release files follow the same pattern. A Nix option exists: nix run github:storytold/lightcraft.

One-prompt version: "Install lightcraft from the latest release at github.com/storytold/lightcraft. Verify the checksum and wait for my yes before you install. Then set up lightcraft-cli as an MCP server on my photo folder ~/Pictures/shoot, and tell me the tools you can call."

Check it works: "Render a sample JPEG with light.exposure set to 0.5 using lightcraft-cli and show me the output file." Source build: cargo run --release -p lightcraft for the app and cargo run --release -p lightcraft-cli -- render photo.jpg -o out.jpg --set light.exposure=0.5 for the CLI. Chinese and Japanese text show no glyphs unless you clone craft-fonts and set CRAFT_FONTS_DIR.

vectorcraft — install

Files: vectorcraft-<ver>-windows-x64.msi, vectorcraft-<ver>-macos-universal.dmg, vectorcraft-cli-<ver>-macos-universal.zip, Linux and FreeBSD files. On macOS a source build can also make an app bundle with cargo xtask bundle (output dist/VectorCraft.app).

One-prompt version: "Install vectorcraft from the latest release at github.com/storytold/vectorcraft for my machine. Verify the checksum, show me the plan and wait for my yes. Then register vectorcraft-cli as an MCP server with the mcp argument and list the tools you can call."

Check it works: "Clone the repo, run the example examples/ribbons.vectorcraft through vectorcraft-cli, export out.pdf, and tell me what the file contains." Files: filmcraft-<ver>-windows-x64.msi, filmcraft-<ver>-macos-universal.dmg, filmcraft-cli-<ver>-macos-universal.zip, Linux and FreeBSD files. Files: effectcraft-<ver>-windows-x64.msi and -portable.zip, effectcraft-<ver>-macos-universal.dmg, effectcraft-cli-<ver>-macos-universal.zip, Linux (for example effectcraft-<ver>-linux-x86_64.AppImage) and FreeBSD files. The README says building needs Rust 1.95 or newer.

How to use each craft from Claude Code or Codex (for a non-designer)

You need no design skill to start. Each app has a command line tool and an MCP server. An MCP server is a small program that lets an agent call the app's commands as tools. You tell the agent what you want in plain words. The agent calls the commands. You open the result in the app and adjust it if you want. Every command string below comes from the repo READMEs, which I read on 2026-10-08. The prompts are my examples, and I did not run any of them. All tools are built with Rust, so you need Rust 1.95 or newer to build them from source. The repos also publish downloads, for example a macOS zip for photocraft-cli.

The setup is the same for each app. In Claude Code, register the server once, for example claude mcp add vectorcraft -- /path/to/vectorcraft-cli mcp. In Codex, you add the same command and arguments to the file ~/.codex/config.toml (on Windows, C:\Users\<you>\.codex\config.toml). Each server is one table named [mcp_servers.<name>] with a command key and an optional args list. The key must be mcp_servers with an underscore, not mcpServers. The READMEs show only the Claude Code form. I took the Codex form from the OpenAI Codex MCP documentation. Each repo also has an AGENTS.md file. Tell the agent to read it first.

Codex configuration for the seven apps

Replace each path with the real path of the binary you built or downloaded. In TOML, use single quotes around a Windows path so that the backslashes stay literal. Add only the apps that you want.

# ~/.codex/config.toml

[mcp_servers.pdfcraft]
command = 'C:\tools\craft\pdfcraft-cli.exe'
args = ["mcp", "--root", 'C:\Users\you\Documents\pdfs']

[mcp_servers.photocraft]
command = 'C:\tools\craft\photocraft-cli.exe'
args = ["mcp"]

[mcp_servers.lightcraft]
command = 'C:\tools\craft\lightcraft-cli.exe'
args = ["mcp", 'C:\Users\you\Pictures\shoot']

[mcp_servers.vectorcraft]
command = 'C:\tools\craft\vectorcraft-cli.exe'
args = ["mcp"]

[mcp_servers.filmcraft]
command = 'C:\tools\craft\filmcraft-cli.exe'
args = ["mcp"]

[mcp_servers.effectcraft]
command = 'C:\tools\craft\effectcraft-cli.exe'
args = ["mcp"]

[mcp_servers.designcraft]
command = 'C:\tools\craft\designcraft-cli.exe'
args = ["mcp"]

Same setup from the command line: codex mcp add pdfcraft -- C:\tools\craft\pdfcraft-cli.exe mcp --root C:\Users\you\Documents\pdfs. The -- separates the Codex options from the server command. Then run codex mcp list to see the servers and codex mcp get pdfcraft to see one entry. Inside Codex, the /mcp command lists the active servers. Restart Codex after you edit the file.

Claude Code equivalents (from the READMEs): claude mcp add vectorcraft -- /path/to/vectorcraft-cli mcp and claude mcp add lightcraft -- "$PWD/target/release/lightcraft-cli" mcp ~/Pictures/shoot.

Caveats: the mcp sub-command with these arguments is stated in the READMEs for pdfcraft, photocraft, lightcraft, vectorcraft and filmcraft. The effectcraft README also names effectcraft-cli mcp. For designcraft the README says an MCP server mode exists and points to docs/mcp.md, but the text I read did not give the exact sub-command. I assumed mcp by analogy with the others. Run designcraft-cli --help to confirm. The example paths and the .exe names are placeholders. I did not test any entry.

pdfcraft (Acrobat) — easiest start

Use it for PDF chores that you now do by hand. The server runs only while the agent starts it, opens no network port, and the --root flag limits file access to one folder. Config: {"mcpServers":{"pdfcraft":{"command":"pdfcraft-cli","args":["mcp","--root","/path/to/your/pdfs"]}}}.

Example prompts (copy, then change the file names):

  • Assemble: "Use the pdfcraft tools. In the folder I gave you, combine report.pdf and appendix.pdf into combined.pdf. Then delete page 5, rotate pages 1 and 2 by 90 degrees, set the title to 'Q3 Review', and save as final.pdf. Tell me the page count before and after."
  • Split: "Split annual-report.pdf into parts of 10 pages each in a parts/ folder. Then list each part with its first line of text, so I can name the files."
  • Extract: "From report.pdf, extract pages 1, 3 and 5 into highlights.pdf. Do not change the original."
  • Read and summarise: "Read paper.pdf page by page in reading order. Write a one-page summary in plain words. After each claim, give the page number."
  • Search: "Search every PDF in the folder for the word 'invoice'. Give me a table: file name, page number, and the sentence that contains the word."
  • Inspect a form: "Show the structure of form.pdf. List every field name and tell me which fields are empty."
  • Safe first pass: "Plan the edits and list them. Do not save until I say 'save'." (Edits stay in memory and can be undone until the agent saves.)

Direct commands from the README: pdfcraft-cli combine report.pdf appendix.pdf --out combined.pdf, pdfcraft-cli split report.pdf --every 10 --out-dir parts/, pdfcraft-cli text paper.pdf --page 3. Edits stay in memory and can be undone until the agent saves. The README says Office import and export is missing.

photocraft (Photoshop)

Use it to fix or batch-process pictures. It reads and writes PSD and PSB, PNG, JPEG, WebP, AVIF and others, and it has more than 500 registered commands. Start the server with photocraft-cli mcp.

Example prompts:

  • Fix one picture: "Open wave.psd with photocraft. Apply Smart Sharpen at amount 80. Add a curves adjustment layer with the points (0,0), (64,48), (192,212), (255,255). Export wave-final.png. Then list the commands you ran, in order."
  • Batch a folder: "Write a grade.json action list that sharpens each image and lifts the contrast with a curves layer. Apply it to every image in ./raw. Save the results in ./graded. Do not overwrite ./raw."
  • Find the right command: "I want to remove a color cast. List the photocraft commands that relate to color balance. Pick one, run it on test.png, and show me the output file name."
  • Convert formats: "Convert all PNG files in ./assets to WebP and AVIF. Keep the same file names. Report the size of each file before and after."
  • Check the layers: "Open design.psd. List all layers by name and type. Tell me which layers are hidden."
  • Attach to the app: "Start photocraft with --control. Take a screenshot of the current canvas and tell me what you see." (The README says the control channel inspects UI state and takes screenshots.)

Direct commands from the README: photocraft-cli run wave.psd --cmd filter.sharpen.smartSharpen --params '{"amount":80}' --out wave-final.png and photocraft-cli batch --actions grade.json --in ./raw --out ./graded. HEIC photos are read-only and need a build option (--features heif).

lightcraft (Lightroom)

Use it to correct a whole folder of camera photos. It reads RAW files from Canon, Sony, Nikon, Fujifilm, Panasonic, Pentax, Olympus and DNG. CR3 files open only as embedded previews. Register with claude mcp add lightcraft -- "$PWD/target/release/lightcraft-cli" mcp ~/Pictures/shoot. A second mode, with --connect 127.0.0.1:7980, attaches to the running app so the agent can take screenshots and click.

Example prompts:

  • One RAW photo: "Import in.dng. Set light.exposure to 0.7. Export out.jpg with the long edge at 2048 pixels. Show me the JSON result of each command."
  • Learn the controls: "List the develop controls. For each slider, give the range, the default and the current value. Group them into light, color and detail."
  • Whole shoot: "The library folder holds a wedding shoot. Apply exposure +0.5 to every photo. Export all as JPEG, long edge 2048, to ./web. Keep the originals unchanged."
  • Compare: "Render photo.jpg three times with light.exposure set to 0.3, 0.5 and 0.7. Save out-03.jpg, out-05.jpg and out-07.jpg. Tell me which looks best, and explain why."
  • Check the RAW format: "List which of my files will open as full RAW and which will open only as embedded previews." (The README says CR3 files open only as previews.)
  • Undo: "Make three exposure changes, then undo the last one." (A scripted burst of slider updates counts as one undo step.)

Direct command from the README: lightcraft-cli render in.dng -o out.jpg --set light.exposure=0.7. Agent actions are undoable. A scripted burst of slider updates counts as one undo step.

vectorcraft (Illustrator)

Use it for logos, icons and diagrams that stay sharp at any size. Native files are JSON (.vectorcraft). It imports and exports SVG and PDF, and PDF-compatible .ai. Register with claude mcp add vectorcraft -- /path/to/vectorcraft-cli mcp. The README says its bundled examples were built through the same command API that the MCP server exposes.

Example prompts:

  • New logo: "Using vectorcraft, draw a logo: a blue circle (#1D4ED8), 200 units wide, with a white letter S in the center. Save it as logo.vectorcraft. Export logo.svg and logo.pdf."
  • Variants: "Open logo.vectorcraft. Make five color variants: red, green, orange, black and white-on-black. Export each as an SVG named logo-red.svg and so on."
  • Icon set: "Draw four simple icons on a 24 by 24 grid: home, search, mail, settings. Use a 2-unit stroke and no fill. Export each one as its own SVG."
  • Convert: "Open the .ai file I gave you. Export it as SVG and as PDF. Tell me anything that did not convert." (The README says .ai files are PDF-compatible.)
  • Business card: "Make a business card, 90 by 50 mm, with my name, title, e-mail and a thin line under the name. Export PDF. Ask me for the text before you start."
  • Check an example: "Run the example examples/ribbons.vectorcraft, export out.pdf, then describe what it contains layer by layer."

Direct command from the README: cargo run --release -p vectorcraft-cli -- run --in examples/ribbons.vectorcraft --export out.pdf.

designcraft (InDesign)

Use it for multi-page layouts: a flyer, a report, a magazine spread. It has spreads, parent pages, threaded text frames and styles. It imports and exports IDML and exports PNG. PDF export is planned. The README says AI agents can edit documents through a JSON channel and an MCP server. Headless rendering command: cargo run --release -p designcraft-cli.

Example prompts:

  • Magazine spread: "Use designcraft. Create a two-page spread. Put a large headline across the top, the article text below it in three columns with threaded text frames, a pull quote in the middle, and a picture on the right page. Export PNG. The article is in article.txt."
  • Styles: "Create a paragraph style 'Body' (11 pt, justified) and a style 'Headline' (36 pt, bold). Apply 'Body' to all text frames except the title."
  • One-page flyer: "Make an A4 flyer for a bake sale on 12 November, 10:00 to 14:00. Use a big title, a short list of items, and the address at the bottom. Ask me for the address first."
  • Repeating pages: "Make a parent page with a page number at the bottom right and a thin line at the top. Make an 8-page document that uses it."
  • Open an existing layout: "Import brochure.idml. List the pages, the text frames and the styles. Then change the main font size in the 'Body' style to 10 pt and export PNG."
  • Check line breaks: "Render the document headless and check that no paragraph ends with a single word on its last line." (The README says line breaks match on screen and in PDF.)

The video author made a magazine spread this way from one prompt. The README did not list exact CLI sub-commands for DesignCraft in the page text that I read, so ask the agent to read AGENTS.md and list the available commands.

effectcraft (After Effects)

Use it for animated graphics: logo reveals, titles, lower-thirds. It has compositions, layers, keyframes, 306 effects, expressions, 3D cameras and lights, a render queue, and Lottie import and export. Project files are readable JSON (.ecproj). It cannot open .aep files. It has effectcraft-cli with render, set-property and run-command functions, and an MCP server mode. The README did not give exact command strings in the text that I read.

Example prompts:

  • Logo reveal: "Using effectcraft, make a 5-second composition, 1920 by 1080, 30 frames per second, dark navy background. Import logo.png. Scale it from 0 to 100 percent over the first second with an ease-out curve, sweep a lens flare across it at second 2, and fade everything out in the last 10 frames. Save the project as logo.ecproj and render an MP4."
  • Title: "Add a title 'Launch Day' that types on letter by letter, with a soft drop shadow. Show it from second 1 to second 4."
  • Lower third: "Make a lower-third bar for a speaker named 'Dr. Ada Lin, Researcher'. The bar slides in from the left, stays 4 seconds, then slides out. Render with a transparent background."
  • Lottie: "Export the animation as Lottie JSON for my website. Then list any effect that Lottie cannot express."
  • Polish pass: "List all the layers in logo.ecproj. Tell me which effects are applied to each layer. Suggest three changes that would make the motion feel smoother, and apply the ones I approve."
  • Explore: "List the effect categories. Show five effects I could use for a retro TV look and add two of them to the title layer."

Because project files are readable JSON, you can ask: "Open the .ecproj file as text and explain what each layer does."

The video author made a logo animation from one prompt, with editable layers. Ask the agent to run effectcraft-cli help first and to read AGENTS.md.

filmcraft (Premiere Pro)

Use it to cut video: join clips, trim, add titles, export. It has more than 650 engine commands. It decodes and encodes H.264, ProRes, DNxHD/DNxHR and MJPEG in MP4, MOV and Matroska. HEVC, VP9 and AV1 are decode-only. It exchanges projects with Final Cut Pro XML, OpenTimelineIO, EDL, AAF and OMF.

Commands from the README: cargo run --release -p filmcraft-cli -- commands lists every engine command. cargo run --release -p filmcraft-cli -- mcp starts the headless MCP server.

Example prompts:

  • Discover first: "Run filmcraft-cli commands. Group the engine commands by task (import, cut, audio, titles, export) and show me the ten I will need most."
  • Simple edit: "Create a sequence. Place intro.mp4, then demo.mp4. Trim the first 3 seconds off demo.mp4. Add a 1-second cross dissolve between them. Export H.264 in an MP4."
  • Silence removal: "Remove silences longer than 1 second from interview.mp4. Keep 0.2 seconds of padding. Export interview-tight.mp4. Tell me how much time you removed."
  • Music bed: "Add music.mp3 under the whole sequence. Lower it to -18 dB where someone speaks. Fade it out over the last 2 seconds."
  • Titles: "Add a title at second 2 with the text 'Season Opener' and an opening position and scale animation."
  • Hand off to an editor: "Export the timeline as a CMX 3600 EDL and as OpenTimelineIO so a colleague can open it in another editor."
  • Scale cut: "Take my 40-minute recording, find five 30-second highlights, and put them in one sequence with title cards between them. Show me the list of cuts before you render."

Some of these prompts depend on commands that exist only if the command list shows them. Ask the agent to check the list and report any step it cannot do. The README lists import, export, codec and interchange formats. It does not list a silence-removal command, a music-ducking command or a highlight finder, so the agent may need to combine other commands or tell you that it cannot do the step.

Suggested order for a beginner: start with pdfcraft, because the task (combine, split, read PDFs) needs no design knowledge. Then try vectorcraft for a logo, then effectcraft to animate it. This order is my suggestion. It is not from the sources.

Caution: the video author rates the agent output as a first draft ("somewhat okay, not always the best"). Expect to open the result in the app and adjust it.

Practical takeaways

The video argues that these tools still matter in a market with strong image and video generators, because generated output is hard to polish and layered tools give control over each element. The strongest evidence offered is two single-prompt tests by one reviewer. Treat the maturity of each application as unmeasured. Only effectcraft has a stated limit (no .aep import), and only designcraft has a stated gap (no PDF export). The video reports 20,000 stars on photocraft a few hours after launch; the org page showed 23k on 2026-10-08.
